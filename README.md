# choulaogong-onlyno999 · 丑老公 · 漂亮老婆 Agent

「丑老公·漂亮老婆」反差夫妻自拍秀专用生产 Agent。

- **丑老公 = 刁哥（秃头版）**：脸 1:1 锁原定妆卡，摘帽剃光头，土味日常装，搞怪得意表情，手持自拍当前景（人形自拍杆）。
- **漂亮老婆 = 用户老婆**：脸 1:1 锁其定妆，先素颜家居出镜立钩子，随后硬切多套华丽变装逐套展示，最后一套相拥收尾。
- **固定场景「家」**：两口子的土味老家小院（白瓷砖自建房＋红铁门＋鸡舍柴火菜地），全期复用、结构锁死；每期只许 1–3 处物件层微变（晾晒/作物/三轮车位置/桌上物/门贴等）。
- **生产**：开工先走咨询问卷（时长/变装清单/钩子句与视角/场景微变/对白/画幅），未确认不开拍；出片调用 H3pro-onlyno999（MiniMax H3）全流程——秃头定妆→造型锚点→官方英文六段式提示词→逐段派发质检→硬切拼片＋后期叠字→门禁交付。
- **格式母本**：2026-10-04 用户案例（14.53 秒：约 5 秒钩子段＋6 套变装×约 1.6 秒硬切＋相拥收尾），逐镜拆解见 `references/case_2026-10-04_anatomy.md`。
